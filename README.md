

# Nogo Home Services Platform

A mobile-based home services application developed as part of a team internship project. The platform enables users to browse service categories, interact with a chatbot for service discovery, and receive booking confirmations via SMS.

---

## 🚀 Features

- 📱 Cross-platform mobile app built with React Native
- 🤖 Conversational AI using Dialogflow ES
- 🏠 6+ service categories (AC services, electrician, plumbing, spa, massage, cleaning)
- 📩 Automated booking confirmation via Twilio SMS API
- 🗂 Categorized service navigation and chatbot-driven assistance

---

## 🛠 Tech Stack

- React Native (Mobile Application)
- Dialogflow ES (Chatbot)
- MySQL (Database)
- Twilio SMS API (Notifications)
